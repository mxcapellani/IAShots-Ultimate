# Installation and updates

Clone `https://github.com/mxcapellani/IAShots-Ultimate.git` or download the project. Copy `.agents/skills/iashots-ultimate/` intact into the host-supported directory. The nucleus is self-contained; references and validator deepen and verify its use.

Assign actual image roles clearly. A scene image does not authorize copying physical identity. Without separate identity, keep physical attributes neutral. Check the destination generator's actual reference support separately.

For updates, keep customizations separately, read changelog, replace the full skill folder, run structural tests and repeat relevant visual cases. Do not relax output order or identity separation to pass a superficial test.
