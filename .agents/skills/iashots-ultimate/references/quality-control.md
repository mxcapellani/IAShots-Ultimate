# Quality control

Before returning: verify image access, role map, observed composition, independent identity, English values, clothing/pose specificity, spatial and lighting consistency, exact ten-key order and clean raw JSON.

If a reference is missing, do not fabricate it to satisfy output format. If a detail is uncertain, omit specificity or use a truthful neutral description. If a requested variation changes background only, conserve unrelated fields and update only affected light/reflection context where physically required.

Review generated images only when they are supplied and accessible. Distinguish prompt defect from generator variability. Actual parity needs paired execution, not just a validator passing.
