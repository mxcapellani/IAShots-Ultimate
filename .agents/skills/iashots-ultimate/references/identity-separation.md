# Identity independence

Case 1: only scene image — subject remains physically neutral; do not copy face, skin tone, hair, ethnicity, bone structure or presumed gender. Case 2: scene A plus identity B — A defines composition, B defines desired identity. Case 3: several sources — name roles and priorities explicitly.

Pose, clothing and gaze are transferable composition attributes; personal physical identity is not. Do not mix two reference faces. For multiple subjects, establish which identity maps to which position. Inaccessible identity cannot be described as inspected.

Text instructions do not guarantee exact likeness. Actual identity/fidelity evaluation requires authorized reference assets and rendered results. This document is a compositional procedure, not an identity-recognition tool.
